# ECU Fuel Injection Modeling (IPCO Internship)

## Project Overview
This project was conducted during an internship at Iran Khodro Powertrain Co. (IPCO) in the Electronics and Control Department.

## Tasks Performed
*   Analyzed and modeled the Engine Control Unit (ECU) fuel injection system.
*   Studied control logic, calibration tables, and data conversion.
*   Investigated four main control modules (GK, RKTI, ESVW, ESWE) using MATLAB/Simulink.
*   Analyzed the impact of environmental parameters (temperature, rail pressure) on fuel injection timing.
